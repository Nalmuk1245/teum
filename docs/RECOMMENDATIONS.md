# arb-cockpit — 개선·기능 추천 (우선순위)

> 세션 작업 중 파악한 것 기준. "돈을 벌게/잃지 않게 하는 순서"로 정렬.
> 각 항목에 **가치**와 **비용**(구현 규모)을 표기.

---

## A. 지금 돈이 되는데 안 된 것 (실전화 직결)

### A1. cross-cex 실배선 — 가치 높음 · 비용 중
해외 CEX 간(바낸↔바이빗↔OKX) 현물 가격차. **전송이 필요 없어(둘 다 USDT) 김프보다 리스크·비용이 낮고 실전화가 제일 싸다.** 어댑터·게이트 모델은 이미 있고 스텁만 채우면 됨. 김프가 역프일 때의 대체 수익원.

### A2. funding-basis 실행 배선 — 가치 중 · 비용 높음
펀딩비 차익(캐시앤캐리). 감지·감쇠 모델은 있고 실행만 미배선. HL/Lighter 같은 perp-DEX 주문 라우팅이 필요해 비용이 큼. **시장 방향과 무관한 중립 수익**이라 김프·cex-dex가 마를 때 유용.

### A3. 실호가(quote) 속도 — 가치 중 · 비용 낮
과거 "실호가 느림" 지적. 현재 종목 선택 시 양쪽 오더북을 동기 조회. **오더북 마이크로캐시(200~500ms) + WS 오더북 상시 구독**으로 클릭→견적 지연을 없앨 수 있음. 상장 순간엔 이 지연이 곧 손실.

## B. 리스크(안 잃게) — 남은 가드

### B1. 주소별 핫월렛 Δ/분 — 가치 중 · 비용 중
지금 핫월렛 증감은 **거래소 단위**로만 추적(드릴다운 잔고는 주소별로 보이지만 증감은 아님). 주소 단위 스냅샷을 저장하면 "어느 핫월렛이 지금 채워지나"(덤프 임박) 정밀 감지 가능. 상장따리에서 가장 값진 선행 신호.

### B2. 일손실 한도에 미실현 손실 반영 — 가치 중 · 비용 낮
현재 `checkEntry`는 **실현 손익만** 봄. 전송 중 급락으로 진행 런이 큰 미실현 손실이어도 신규 진입을 안 막음. inFlight 런의 미실현을 합산해 한도 판정하면 노출 중첩 방지.

### B3. FX(USDT/KRW) 급변 진입 보류 — 가치 낮 · 비용 낮
`transferRisk`가 FX 드리프트를 계산만 하고 실행은 안 막음. 김프는 원화 정산이라 USDT/KRW 급변 중엔 진입 보류가 안전.

## C. 물량·정보 (상장따리 정밀화)

### C1. 솔라나 핫월렛 잔고 — 가치 중 · 비용 중
holdings가 현재 EVM(ETH/BSC/Base)만. **솔라나 상장이 잦은데** getTokenAccountsByOwner 별도 경로가 필요(멀티콜 구조가 달라). 아비트럼·베이스 등 EVM 확장(QUERY_CHAINS)은 1~2시간, 솔라나는 별도.

### C2. 개장 전 입금 시계열 자동 주소 추정 — 가치 중 · 비용 높
지금은 수동 등록 + 익스플로러 도우미. **상장 발표 후 급등장한 대형 수신 주소를 자동 후보로 제시**하면(오탐 주의) 손이 덜 감. 익스플로러 API로 "최근 24h 대형 유입 주소" 스캔.

### C3. 빗썸 잔고·입금 서명 — 가치 낮 · 비용 중
빗썸 v1 HMAC-SHA512 서명 미배선(입출금 상태는 공개라 됨). 잔고·입금주소 조회가 필요하면.

## D. 아키텍처·최적화

### D1. 실행엔진 프로세스 분리 (2단계) — 가치 조건부 · 비용 높
1단계(서버 모듈 이동)는 완료. UI 재배포가 엔진을 못 죽이게 하려면 별도 데몬. **지금 1인·분단위 운영엔 과투자** — 실행 빈도가 높아지거나 무중단이 중요해질 때. 경계(runEngine이 react 미임포트)는 이미 지켜둠.

### D2. 폴링 → 이벤트 구동 — 가치 중 · 비용 중
스캔 3초 폴링. 상장 감지는 공지 폴링. **거래소 상장 WS/웹훅이 있으면** 3초 벽이 사라져 상장 순간 반응이 빨라짐. 감지 방식이 상장따리 승부의 1순위.

### D3. 대시보드 폴링 통합 — 가치 낮 · 비용 낮
대시보드가 risk/balances/trades/listings/telegram을 각각 폴링. **하나의 `/api/dashboard` 집계 엔드포인트**로 묶으면 요청 수·리렌더 감소. 개인 도구라 체감은 작음.

### D4. React 리렌더 — 가치 낮 · 비용 낮
useLivePrices 600ms recompute가 전체 opp 재계산. 종목 많아지면 memo 세분화 여지. 현재 규모(수십 종목)엔 무해.

## E. UX·편의

- **알림 라우팅 규칙**: 텔레그램 알림에 우선순위(상장>덤프>갭)와 조용시간(야간 뮤트). 지금은 다 즉시.
- **원클릭 프리셋**: 자주 쓰는 규모·헷지·자동레벨 조합을 저장(예: "상장 $500 전자동").
- **거래 성과 리포트**: 전략별·시간대별 실현 net vs 탐지 net 누수 리포트(자동 보정 데이터를 사람도 보게).
- **PWA**: 홈화면 추가 + 푸시. 지금은 텔레그램 의존.

## 지금 당장 추천 (비용 대비 가치 최상 3개)

1. **cross-cex 실배선** (A1) — 전송 없어 제일 싸게 새 수익원, 김프 역프 헤지
2. **주소별 핫월렛 Δ/분** (B1) — 상장따리 선행 신호 정밀화, 이미 잔고 드릴다운 있어 확장 쉬움
3. **실호가 WS 상시 구독** (A3) — 상장 순간 클릭→견적 지연 제거
