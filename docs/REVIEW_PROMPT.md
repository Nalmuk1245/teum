# 아비트라지 시스템 구조 리뷰 요청 프롬프트

> 아래 전문을 복사해서 리뷰어(AI/사람)에게 전달하세요.

---

당신은 크립토 차익거래 데스크의 시니어 퀀트 겸 트레이딩 시스템 아키텍트입니다. 제가 혼자 만들어 운영하는 개인용 반자동 차익거래 시스템의 구조를 설명할 테니, 구조 전체를 비판적으로 평가해주세요. 칭찬보다 허점을 찾는 게 목적입니다.

## 시스템 개요

- **목적**: 김치프리미엄 중심의 반자동 차익거래 콕핏. 1인 운영, 소액(포지션당 수백~수천 달러), 웹 UI에서 감시→원클릭 실행.
- **스택**: Next.js 단일 앱(스캐너·실행기·UI 전부), 3초 주기 스캔 폴링 + 업비트/빗썸 실시간 오더북 WebSocket. 상태는 서버 메모리(globalThis) + JSON 파일 persist. DB 없음.
- **안전장치**: DRY_RUN 기본(실주문은 env 전환+재시작 필요), 킬스위치, 노출·일손실 한도, 슬리피지 상한, 온체인 서명은 화이트리스트 주소로만, 시크릿 파일 0600.

## 전략 4종

### ① 김프 (메인, 완전 배선)
- 업비트/빗썸 KRW 호가 vs 바낸/바이빗/OKX USDT 호가. 환산은 실시간 USDT/KRW(테더 프리미엄 반영).
- 비용 = 양쪽 taker + 코인별 출금 수수료(바낸 networkList 라이브값) + 선물 헷지 왕복비(해당 코인 선물 있을 때) + **자동 보정치**(최근 실거래 20건의 "탐지 net − 실현 net" 평균 leak를 0~1.0%p로 클램프해 가산).
- 실행 게이트: 매수처 출금 가능 + 매도처 입금 가능(거래소 API 실시간 확인), 아니면 net이 커도 실행 불가 처리.
- 전송 리스크 모델: 전송 ETA 동안 노출 = 코인 변동성×√ETA + 점프 테일 + USDT/KRW 드리프트(헷지로도 안 잡힘). 헷지 권고 플래그.
- 갭 지속성 추적: 각 기회의 net 히스토리(30분)로 hit rate·유지시간·변동성 산출, 신뢰도 가중으로 순위 강등/승격.

### ② 크로스 CEX (구조만, 실행 미배선)
해외CEX 간 같은 코인 가격차. 전송 게이트·ETA 동일 모델.

### ③ 펀딩 (감시 전용)
거래소 간 펀딩비 차이를 롱/숏 중립으로 수취. APR 표기, **감쇠 모델**(스프레드 반감기 가정으로 기대 수취 = 삼각형 면적 − 진입왕복비), 200%+ APR은 신규상장 스파이크로 간주해 강등. 실행 미배선.

### ④ CEX-DEX (전송형, 최근 재설계)
- OKX DEX 애그리게이터 실행가능 견적($2000 기준, 라우팅·풀 수수료 포함) vs 바낸 톱오브북. 양방향 계산.
- **전송형 구조**: DEX가 싸면 [DEX 매수 → 지갑→바낸 전송 → 매도], 바낸이 싸면 [바낸 매수 → 지갑 출금 → DEX 매도]. 비용에 전송 다리(전송 가스 or 출금 수수료)와 헷지 왕복비 포함.
- 하드 게이트: 바낸 입금/출금 열림(방향별) + **바낸의 입출금 네트워크가 견적 체인과 일치**해야 실행.
- 유니버스: 하드코딩 코어 + 동적(OKX 토큰리스트 ∩ 바낸 상장, 볼륨 상위, 사이클당 6종 회전). 동적 후보는 **CoinGecko 컨트랙트와 교차검증** — 불일치는 제외, 미확인은 "미검증" 강등+실행 금지. ±8% 초과 갭은 죽은 풀/동명이토큰으로 보고 버림.
- 견적 스윕은 60초 TTL 백그라운드(레이트리밋), 스캔 사이클 비블로킹. 견적 나이 표기.

### 부가: 상장따리 모듈
업비트/빗썸 신규상장 감지(마켓 diff + 공지 파싱 + 텔레그램 채널) → 티커의 컨트랙트를 CoinGecko로 해석(클라이언트가 준 주소는 불신) → OKX로 DEX 원클릭 매수. 자동매수는 이중 옵트인 + fail-closed 가드(CG 미등록/시총 $10M 미만/24h +50% 기펌핑 스킵). 개장 카운트다운, 거래소 핫월렛 잔고 급증 감시.

## 실행 파이프라인

- 기회 클릭 → 단계 상태머신: 매수 → (헷지 숏) → 출금 → (지갑 경유 전송) → 입금 확인 → 매도 → (헷지 청산) → 정산.
- 자동화 레벨 선택: 전수동 / 출금 전 정지 / 매도 전 정지 / 전자동.
- **재검증**: 매수·출금·매도 직전에 엣지 재확인, 소멸 시 중단. **롤백**: 비가역 단계(출금) 전 실패 시 진입 다리 자동 청산, 롤백 실패는 명시 보고. 출금 후 실패는 헷지 유지+수동 처리.
- 헷지는 도착 수량 기준(출금비 차감), 선물 가용 마진 60% 게이트(전송 중 펌핑 시 헷지 청산 방지).
- 지갑 경유는 해외→국내 입금만(트래블룰 우회), 나머지는 거래소 직송. 태그 필수 코인은 태그 없으면 하드 차단.
- 정산 시 실현 net을 기록 → 위 "비용 자동 보정"의 입력이 됨.

## 온체인 인프라

- OKX Web3 API: 지갑 잔고·tx 24 EVM 체인+솔라나+트론 일괄, DEX 스왑 21체인(체인별 기준 스테이블은 실견적 검증 주소), 전송 tx 빌드(sign-info: 가스·논스), 크로스체인 브릿지 견적/실행.
- 서명·브로드캐스트는 전부 로컬(ethers/솔라나 SDK), 프라이빗 키는 서버 파일(0600)만. 스왑 서명은 OKX가 그 호출에서 반환한 라우터로만(화이트리스트), 전송 토큰 컨트랙트는 큐레이션→내 지갑 실보유→토큰리스트 순 자동 해석(모호하면 차단).
